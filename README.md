# SONIQ VISUALS WEB

Мобильный веб-редактор: импорт аудио, обложка, редактируемые название/исполнитель, реальный анализ двух каналов через Web Audio API, визуализатор частот и запись сцены вместе со звуком.

## Запуск
Открой `index.html` в современном браузере. Для корректной работы аудио и записи лучше использовать HTTPS (например, после публикации на Render).

## Публикация на Render
1. Создай публичный GitHub-репозиторий `soniq-visuals-web`.
2. Загрузи в корень репозитория все файлы из ZIP.
3. В Render выбери **New → Static Site** и подключи репозиторий.
4. Build Command оставь пустой; Publish Directory укажи `.`.
5. Нажми Deploy.

## Важно
Запись создаёт WebM, если браузер поддерживает MediaRecorder. MP4 не заявлен: поддержка MP4-кодирования в мобильном браузере неодинакова. Стерео-индикатор использует измерения левого и правого каналов, но пока показывает баланс каналов как одну движущуюся точку.
